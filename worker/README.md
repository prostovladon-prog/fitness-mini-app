# ATOM: пробный период, подписка Stars, бонус за канал

Пока вы ничего не настроили на сервере, **приложение работает как раньше** — никаких экранов оплаты нет.
Платёжная часть включается сама, как только воркер начнёт отвечать `enabled: true` на `/api/config`.

Условия (меняются переменными, см. ниже): 4 дня бесплатно → +3 дня за подписку на канал (итого 7) → 250 ⭐ / 30 дней. После окончания приложение закрыто экраном оплаты (доступен только экспорт своих данных).

## Что сделать (≈15 минут)

### 1. Код воркера
1. Cloudflare → Workers → ваш `atom-proxy` → Edit code.
2. Откройте `worker/atom-access.js`, скопируйте **весь файл** и вставьте **в начало** кода воркера.
3. В самом начале вашего `fetch(request, env)` добавьте:
   ```js
   const atomResponse = await atomAccessHandle(request, env);
   if (atomResponse) return atomResponse;
   ```
4. В ветках `/ai-chat` и `/food-search` — до обращения к внешним сервисам — добавьте проверку подписки (это и есть настоящая защита, на стороне приложения её можно обойти):
   ```js
   const denied = await atomRequireAccess(request, env);
   if (denied) return denied;
   ```
5. В заголовках CORS вашего воркера для этих веток разрешите `X-Telegram-Init-Data` и `X-Atom-Token` (`Access-Control-Allow-Headers`), иначе браузер заблокирует запросы приложения.

### 2. Хранилище
Workers & Pages → KV → Create namespace (`atom-kv`). В воркере: Settings → Bindings → KV namespace → имя переменной **`ATOM_KV`**.

### 3. Секреты и переменные (Settings → Variables)
| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен бота из @BotFather (**никому не отправляйте**, в том числе мне) |
| `WEBHOOK_SECRET` | Secret | любая длинная случайная строка (например 40 символов) |
| `TOKEN_SECRET` | Secret, необязательно | ещё одна случайная строка (подпись кодов привязки) |
| `BOT_USERNAME` | Text | имя бота без `@` |
| `CHANNEL` | Text | **заглушка для канала**: `@имя_канала`. Пока канала нет — не создавайте переменную: бонус не показывается, пробный период 4 дня |
| `PRICE_STARS`, `TRIAL_DAYS`, `BONUS_DAYS` | Text, необязательно | цена и сроки (по умолчанию 250 / 4 / 3) |

### 4. Вебхук Telegram (чтобы приходили платежи)
Откройте в браузере один раз (подставьте свои значения):
```
https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://atom-proxy.prostovladon.workers.dev/api/tg-webhook&secret_token=<WEBHOOK_SECRET>&allowed_updates=["message","pre_checkout_query"]
```
Должно ответить `{"ok":true,...}`.

### 5. Канал
1. Создайте канал, впишите его имя в `CHANNEL` (например `@atom_fitness`).
2. Добавьте своего бота в канал **администратором** — без этого Telegram не даст проверить, подписан ли пользователь.

### 6. Проверка
- `https://atom-proxy.prostovladon.workers.dev/api/config` → `{"enabled":true,...}`
- Откройте приложение через бота: вверху «Пробный период: осталось 4 дня».
- Платёж Stars проверьте своим аккаунтом (для теста можно временно поставить `PRICE_STARS=1`).

## Как это работает
- Пробный период стартует при первом открытии через Telegram; личность пользователя подтверждается подписью Telegram (`initData`, HMAC), подделать её нельзя.
- Бонус: сервер вызывает `getChatMember` и один раз прибавляет дни; нельзя получить бонус после 7-го дня.
- Оплата: `createInvoiceLink` (валюта `XTR`, подписка 30 дней) → `pre_checkout_query` → `successful_payment`; повторные доставки платежа игнорируются.
- Установленное на главный экран приложение не видит `initData`, поэтому в Telegram (Настройки → Подписка → «Скопировать код привязки») берётся одноразово выданный код и вставляется в установленном приложении.
- Если сервер недоступен, приложение **не блокируется** (сбой сервера не должен оставлять платящих без доступа).
